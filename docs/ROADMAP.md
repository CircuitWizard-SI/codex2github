# 路线图

## 已有功能

- [x] GitHub Issue 远程入口与原会话续接
- [x] 单会话模型切换与新任务默认模型
- [x] 引导、排队、撤回和送达可视化
- [x] 文件事件触发的会话列表和历史镜像
- [x] 主会话／子代理分类，显式关闭规则
- [x] 配置化、可安装 Python 包、合成数据测试及 CI

## 近期维护方向

- [ ] 固定并记录支持的 Codex 版本与历史数据库变更
- [ ] 增强执行器和配置迁移的集成检查
- [ ] 从现有路由器提取稳定的会话／队列服务接口
- [ ] 提升网络中断时的恢复和交付状态观测

## 可选客户端方向

- [ ] 独立移动端 App：会话列表、对话、引导、队列管理与通知
- [ ] 桌面客户端：原会话定位、任务面板和同步状态
- [ ] 新传输适配器及认证后的服务接口
- [ ] 多用户／组织仓库授权和细粒度权限

这些方向尚未实现，也没有承诺完成日期。当前入口继续使用 GitHub 网页。
